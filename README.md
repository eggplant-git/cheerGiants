# 🔶 GIANTS 応援歌全曲集

読売ジャイアンツの応援歌をスマホで見やすく一覧できるウェブページです。

## 📋 収録内容（2026年版）

- **選手別応援歌**（野手19名・投手7名 計26曲）
- **共用ヒッティングマーチ**（ヒッターズテーマA/B・ピッチャーズテーマ1〜3・四球のテーマ）
- **チャンステーマ**（Gフレア・勝ち取れ！・バタフライ・ファイター・ヒッパレ・スパルタンX）
- **その他の応援歌**（初回ファンファーレ・サイクロン・GOGOジャイアンツ）
- **球団歌**（闘魂こめて・VIVA GIANTS）

## ✨ 機能

- 🔍 **選手名・歌詞で検索** — 該当箇所をハイライト表示し自動展開
- 📱 **スマホ最適化** — 球場でもサッと確認できるモバイルファーストデザイン
- 🗂️ **カテゴリタブ** — 選手別 / 共用テーマ / チャンス / 球団歌 で絞り込み
- 📖 **アコーディオン表示** — 歌詞をタップで開閉

## 🚀 GitHub Pages で公開する

1. リポジトリを作成してこのファイルをアップロード
2. Settings → Pages → Source: `main` branch, `/ (root)`
3. 数分後に `https://<username>.github.io/<repo>/` でアクセス可能
